# StudyPal 项目结构说明

> 本文档已更新至 v2.0（2026-04-30）。如需完整功能介绍，请参阅根目录的 `README.md`。

## 项目概述

StudyPal 是一个基于 Flask 的考研智能学习搭子 Web 应用，集成了 AI 对话、三层记忆系统、主动关心引擎、考研日记、番茄钟、任务管理、成就系统等完整功能。

## 架构说明

### 前端（单页应用）

- `templates/index.html`：单文件包含全部 HTML 结构，内联 JavaScript 实现 App 逻辑
- 8 个页面：首页、聊天、记忆、任务、计划、成就、日记、设置
- CSS 模块化：变量 → 基础 → 组件 → 动画分层
- JS 模块化：API 调用层 → 状态管理 → 工具函数

### 后端（Flask Blueprint）

- 每个功能模块对应一个 Blueprint
- Blueprint 下按 HTTP 方法组织路由（GET/POST/PUT/DELETE）
- 所有 API 端点以 `/api` 为前缀

### 核心模块依赖关系

```
buddy.py (搭子核心)
├── buddy_profile.py  ← 获取用户档案
├── buddy_memory.py   ← 读取/写入记忆
├── caring_engine.py  ← 触发关心事件
└── ai_helper.py     ← 调用 Ollama

ai_helper.py
├── prompt_templates.py
└── ai_memory.py (对话历史)
```

## 快速开发

```bash

# 启动服务
python app.py
```
